## 打包后交互验证

通过 PowerShell 演示脚本启动最终 JAR，实际输入命令并检查终端与文件：

- 创建 CLI-A、CLI-B 两个任务，均独立交付；源示例仓库没有新增结果文件。
- `/show` 展示结果，`/diff` 输出含新增文件的补丁，`/accept` 标记完成。
- `[ask]` 任务进入等待回复，`/follow` 后完成。
- `[command]` 任务展示审批，批准 `echo superagent-demo` 后退出码为 0，日志包含命令输出。
- 等待审批时退出并重新启动，任务保留；旧审批报“已处理或失效”，恢复后生成新的审批 ID。
- 后台通知通过 JLine 展示；中文普通输入可触发澄清或创建任务，任务文件保留中文原文。
