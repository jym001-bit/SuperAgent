# 企业级演进路线图

本文件是当前阶段的工作基线：说明「已经有什么、下一步做什么、怎样算做完」。它描述的是工程判断，不是市场宣传；没有真机验收的项一律标注为未验证。

参考的架构来源是 DeepSeek 公开的 Super-agent 原型文档（Router / Worker / 事件接入 / 持久化执行 / 沙箱执行）。本项目是独立实现，不复制其源码。

## 定位

- **不是 demo**：单机闭环已经完整（任务持久化、审批、取消恢复、补丁交付、三个入口），现在缺的是**企业级属性**：可扩展的执行内核、可观测性、可运维、可量化评测、可交付。
- **不夸大**：离线模拟只证明调度与工具链路；真实模型质量、容器隔离、GitHub 联调必须单独验收并留下证据。

## 阶段计划

### P1 执行内核（当前主攻）

| 任务 | 做法 | 验收标准 |
|---|---|---|
| T1.1 schema v2 | `tasks` 只存骨架 + `status`/`updated_at` 列；对话与工具调用拆到 `task_messages` / `task_calls` 追加表；`user_version` 标记版本；旧库自动迁移并留 `.v1.bak` 备份 | 旧库打开后自动迁移且任务可继续；迁移幂等；`mvn test` 全绿 |
| T1.2 状态列 | 调度查询走 `status` 索引，不再 `json_extract` 全表扫描 | 查询计划确认使用索引；`queued()` 只反序列化排队任务 |
| T1.3 读写分离 | 单写连接 + 线程本地读连接（WAL 快照读）；写路径用 `ReentrantLock` | 并发读不阻塞写；事务内读到未提交改动 |
| T1.4 事件驱动调度 | 显式唤醒 + 250 ms 兜底轮询，取代 30 ms 空转 | 空闲 CPU 下降；任务响应延迟不退化 |
| T1.5 行为级验收 | 规模、并发、迁移、崩溃一致性测试 | 见「测试标准」 |

## 测试标准（用户明确要求）

**不写凑数测试。** 判断标准：一个测试只有在「删掉被测逻辑后它必须失败」时才有价值。

允许的测试类型：

- 并发与竞态（两个 Worker 同时在途、取消与写回竞争）
- 崩溃与恢复（子 JVM 强杀、事务边界、结果不明不重放）
- 规模（数百任务调度吞吐、长任务单步耗时）
- 迁移与兼容（旧库升级、幂等）
- 失败注入（模型错误、命令超时、磁盘写失败、冲突合成）
- 契约一致性（工具注册表与分派表一一对应、指标与真实状态一致）

禁止：getter/setter、常量、构造器、纯格式化的测试。

## 变更纪律

- 行为变更必须同时更新中文文档与对应测试。
- 外部动作先存意图后存结果；结果不明不自动重跑。
- 密钥只存在环境变量或被忽略的本机配置；日志不打印 Key。
- 任务来源仓库只读；补丁交付；禁止自动合并。
